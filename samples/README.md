# Images d'exemple

Déposez ici les images que vous voulez utiliser pour tester la borne.

Elles ne sont pas chargées automatiquement : glissez-les depuis ce dossier vers
la zone de dépôt de la page d'accueil (http://localhost:8080), comme le ferait
un utilisateur de la borne.

Formats acceptés : JPEG, PNG, GIF, WebP, BMP, TIFF, HEIC/HEIF et PDF.
